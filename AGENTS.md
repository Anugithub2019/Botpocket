# Project Instructions

- This is a dependency-free static website. `index.html` contains the page content and structure; `styles.css` contains its visual design and responsive behavior.
- Keep references to local assets relative to the project root. Existing assets include `botpocket-logo.png` and `botpocket-demo.mp4`.
- Preserve semantic HTML, keyboard accessibility, responsive layouts, and the existing BotPocket visual language when making changes.
- Treat pricing, product capabilities, contact details, and other factual marketing copy as intentional; change them only when the request calls for it.
- No build or test tooling is configured. Verify visual changes in a browser at desktop and mobile widths; do not add dependencies or tooling for a static change unless needed.
